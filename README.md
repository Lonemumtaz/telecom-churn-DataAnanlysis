## Overview
This repository contains an end-to-end exploratory data analysis (EDA) project focused on **telecom customer churn**. The goal is to understand patterns behind churn, identify the key drivers, and provide insights that can inform retention strategies.

## Dataset
The analysis uses a telecom churn dataset that typically includes:
- Customer demographics (e.g., gender, senior citizen)
- Account information (tenure, contract type, payment method)
- Services subscribed (internet service, streaming, phone lines)
- Billing details (monthly charges, total charges)
- Target label: **Churn** (Yes/No)

## Key Questions Explored
- Which customer segments churn the most?
- How does tenure affect churn probability?
- Do contract type and payment method influence churn?
- What services are most associated with churn?
- How do monthly and total charges relate to churn?
